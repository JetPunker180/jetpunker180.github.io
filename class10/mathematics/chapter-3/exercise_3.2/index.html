What are the necessary conditions for matrix equality? Two matrices are equal if and only if they have the same order (dimensions) and all their corresponding elements are identical. To find unknown variables (like $x$, $y$, $z$), equate the values in matching row-column positions. If corresponding elements do not align (e.g., $6=7$ in specific configurations), the matrices cannot be equal, making the solution impossible.

How are matrix addition and subtraction performed? These operations are only possible if the matrices have the same order. Perform the operation by adding or subtracting the corresponding elements individually.

How is matrix multiplication executed? Matrix multiplication $A \times B$ requires the number of columns in the first matrix to equal the number of rows in the second matrix. The result is calculated using the dot product of rows from the first matrix and columns from the second matrix. Each element $(i,j)$ of the product is: $(AB)_{ij} = \sum_{k=1}^{n} a_{ik} b_{kj}$.

The Non-Commutative Nature of Matrix Multiplication: In standard arithmetic, multiplication is commutative ($ab = ba$). However, in matrix algebra, multiplication is not generally commutative. As demonstrated by the operation $(A+B)(A-B) \neq (A-B)(A+B)$, the order of multiplication fundamentally changes the resultant matrix. Always compute products in the exact order requested.

Scalar Multiplication: Multiplying a matrix by a scalar $k$ multiplies every element of the matrix by $k$.
