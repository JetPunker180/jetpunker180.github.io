How do we resolve a simultaneous system containing one linear and one quadratic equation? A mixed linear-quadratic system is solved by algebraic substitution.

Example: $2x + y = 1$ and $x^2 + y^2 = 10$

  1. Isolate $y$ from linear equation: $y = 1 - 2x$
  2. Substitute into quadratic: $x^2 + (1 - 2x)^2 = 10$
  3. Expand: $x^2 + 1 - 4x + 4x^2 = 10$ → $5x^2 - 4x - 9 = 0$
  4. Factor: $(5x - 9)(x + 1) = 0$ → $x = -1$ or $x = \frac{9}{5}$
  5. Find corresponding $y$: For $x = -1$, $y = 1 - 2(-1) = 3$; For $x = \frac{9}{5}$, $y = 1 - 2(\frac{9}{5}) = 1 - \frac{18}{5} = -\frac{13}{5}$
  6. Solution set: $\{(-1, 3), (\frac{9}{5}, -\frac{13}{5})\}$

How is algebraic elimination applied when both simultaneous expressions contain purely quadratic terms? Use addition/subtraction elimination.

Example: $x^2 + 3y^2 = 14$ and $3x^2 + y^2 = 6$

  1. Multiply first equation by 3: $3x^2 + 9y^2 = 42$
  2. Subtract second equation: $(3x^2 + 9y^2) - (3x^2 + y^2) = 42 - 6$ → $8y^2 = 36$ → $y^2 = \frac{9}{2}$ → $y = \pm \frac{3}{\sqrt{2}}$
  3. Substitute back: $x^2 + 3(\frac{9}{2}) = 14$ → $x^2 + \frac{27}{2} = 14$ → $x^2 = 14 - \frac{27}{2} = \frac{28 - 27}{2} = \frac{1}{2}$ → $x = \pm \frac{1}{\sqrt{2}}$
  4. Solution set: $\{(\frac{1}{\sqrt{2}}, \frac{3}{\sqrt{2}}), (\frac{1}{\sqrt{2}}, -\frac{3}{\sqrt{2}}), (-\frac{1}{\sqrt{2}}, \frac{3}{\sqrt{2}}), (-\frac{1}{\sqrt{2}}, -\frac{3}{\sqrt{2}})\}$
