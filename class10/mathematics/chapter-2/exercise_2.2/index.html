How are higher-degree or fractional polynomial expressions reduced to quadratic form? Many algebraic equations that are not initially second-degree can be transformed using variable substitution.

Substitution examples:

  • $ax^4 + bx^2 + c = 0$ → let $y = x^2$ (so $y^2 = x^4$) → $ay^2 + by + c = 0$
  • $9x^6 - 3x^3 + 7 = 0$ → let $y = x^3$ → $9y^2 - 3y + 7 = 0$

How do we clear fractions in rational equations? Multiply every term by the lowest common denominator (LCD).

Example: $3x + \frac{4}{6x-2} = -1$ → multiply by $(6x-2)$: $3x(6x-2) + 4 = -1(6x-2)$ → $18x^2 - 6x + 4 = -6x + 2$ → $18x^2 + 2 = 0$ → $9x^2 + 1 = 0$.

Multi-step substitution with binomial groups: For $(y-4)^2 - 7(y-4) = -6$, let $x = y-4$. Then $x^2 - 7x + 6 = 0$ → $(x-6)(x-1)=0$ → $x=6$ or $x=1$.

Back-substitution: $y-4 = 6$ → $y=10$; $y-4 = 1$ → $y=5$ → solution set $\{5, 10\}$.

How do we find cube roots of real numbers? For $y^3 = 125$ → $y^3 - 125 = 0$. Using difference of cubes: $a^3 - b^3 = (a-b)(a^2 + ab + b^2)$, where $a=y$, $b=5$: $(y-5)(y^2 + 5y + 25) = 0$.

  • Real root: $y = 5$
  • Complex conjugate roots from $y^2 + 5y + 25 = 0$ using quadratic formula
