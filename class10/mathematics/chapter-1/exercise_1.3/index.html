How are solutions derived for pure quadratic equations when the constant is positive? Pure quadratic equations of the form $x^2 + k = 0$ (where $k > 0$) have no real roots because isolating the variable yields a negative radicand, $x^2 = -k$. Taking the square root of both sides gives $x = \pm\sqrt{-k}$. By factoring out the imaginary unit $i = \sqrt{-1}$, the solution resolves into purely imaginary conjugates.

Example: Solving $x^2 + 100 = 0$ yields $x = \pm\sqrt{-100} = \pm10i$, expressed as the solution set $\{\pm10i\}$. Similarly, $x^2 + 7 = 0$ yields $\{\pm\sqrt{7}i\}$.

How do we mathematically verify if a given complex number is a root of an algebraic equation? To check if a complex number like $1+2i$ is a valid solution, substitute the value directly into the variable positions. Expand using algebraic identities and simplify by substituting $i^2 = -1$. If the left-hand side reduces to zero, the complex number is verified as a root.

Important expansion formula: $(a+bi)^2 = a^2 + 2abi + (bi)^2 = a^2 + 2abi - b^2$.

What is impedance in AC circuits? In electrical engineering, alternating current (AC) circuit components are modeled using complex numbers. Total circuit impedance ($Z$) is calculated using Ohm's law for AC systems: $Z = \frac{E}{I}$, where $E$ is voltage and $I$ is current.

Example - Impedance calculation: For voltage $E = 100+10i$ V and current $I = -8+3i$ A:

  • $Z = \frac{100+10i}{-8+3i}$
  • Multiply numerator and denominator by conjugate $-8-3i$:
  • $Z = \frac{(100+10i)(-8-3i)}{(-8+3i)(-8-3i)} = \frac{-800 -300i -80i -30i^2}{64 + 9} = \frac{-800 -380i +30}{73} = \frac{-770 -380i}{73}$
  • $Z = -\frac{770}{73} - \frac{380}{73}i \Omega$
