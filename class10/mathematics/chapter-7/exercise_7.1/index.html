How do we geometrically construct and analytically combine directional physical quantities? A vector is a mathematical object defined by both a scalar magnitude and a specific spatial direction.

Spatial Vector Graphing Rules: Constructing physical vectors requires defining a clear magnitude scale and an angular direction relative to a baseline reference axis.

  • $10$ N force along positive x-axis → points horizontally right
  • $50$ m/s at $150^\circ$ → measure counter-clockwise from positive x-axis → second quadrant

Scalar Multiplication and Scaling: Multiplying a vector $\vec{p}$ by scalar $k$ changes magnitude by $|k|$.

  • $2\vec{p}$ with $\vec{p}$ at $45^\circ$ and length $4$ cm → extends to $8$ cm, same $45^\circ$ direction
  • Negative scalar → reverses direction by $180^\circ$

Multi-Leg Bearing Path Integrations: Bearing is measured clockwise from due North (positive y-axis).

Example - Vehicle Journey:

  1. Leg 1: $15$ km on bearing $30^\circ$
    $\vec{d}_1 = 15\sin30^\circ\vec{i} + 15\cos30^\circ\vec{j} = 7.5\vec{i} + \frac{15\sqrt{3}}{2}\vec{j}$
  2. Leg 2: $8$ km due West
    $\vec{d}_2 = -8\vec{i}$
  3. Total displacement:
    $\vec{d} = \vec{d}_1 + \vec{d}_2 = -0.5\vec{i} + \frac{15\sqrt{3}}{2}\vec{j}$
  4. Magnitude: $|\vec{d}| = \sqrt{(-0.5)^2 + (\frac{15\sqrt{3}}{2})^2}$

Important Distinction:

  • Standard angles: From positive x-axis, counter-clockwise
  • Navigation bearings: From due North (positive y-axis), clockwise
