How do we apply vectors to prove geometric properties of quadrilaterals and analyze internal line ratios? Vector algebra serves as a powerful analytical tool for establishing spatial proofs without relying entirely on synthetic Euclidean geometry.

Parallelogram Vector Properties: A quadrilateral $EFGH$ is a parallelogram if opposite side vectors are equal in both magnitude and direction:

  • $\vec{EF} = \vec{HG}$
  • $\vec{EH} = \vec{FG}$
  • This confirms opposite boundaries are parallel and equal in length.

Computing Diagonal Vector Lengths: For a parallelogram with adjacent sides $\vec{a}$ and $\vec{b}$:

  • First diagonal: $\vec{d}_1 = \vec{a} + \vec{b}$
  • Second diagonal: $\vec{d}_2 = \vec{a} - \vec{b}$

Example: $\vec{a} = 2\hat{i} + \hat{j}$, $\vec{b} = \hat{i} - 3\hat{j}$

  • $\vec{d}_1 = (2+1)\hat{i} + (1-3)\hat{j} = 3\hat{i} - 2\hat{j}$
  • $|\vec{d}_1| = \sqrt{3^2 + (-2)^2} = \sqrt{13}$ units

Midpoint Position Vector Formula:

  • If $E$ is midpoint of $AD$: $\vec{E} = \frac{1}{2}(\vec{A} + \vec{D})$
  • If $F$ is midpoint of $DC$: $\vec{F} = \frac{1}{2}(\vec{D} + \vec{C})$

Ratio Division and Intersection Proofs: Using parametric vector lines along midpoint segment $EF$ and diagonal $AC$, tracking scalar coefficients proves that the intersecting segment divides the main diagonal in a fixed ratio of $1:3$.

Important Sign Rule: When computing $\vec{d}_2 = \vec{a} - \vec{b}$, the negative sign must distribute across both components of $\vec{b}$.
