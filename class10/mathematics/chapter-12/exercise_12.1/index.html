What defines basic statistics? Basic statistics is the branch of mathematics dealing with the collection, organization, analysis, interpretation, and presentation of data. Exercise 12.1 introduces foundational statistical methods including cumulative frequency distributions, class boundary determination, quartile calculations, percentile interpretations, and interquartile range analysis for FBISE 2026 board examination preparation.

How do we construct cumulative frequency distributions? A cumulative frequency column is built by successively adding each class frequency to the sum of all previous frequencies. For a grouped frequency distribution table with intervals and frequencies:

  • Step-by-Step Construction:
    • Step 1: List all class intervals in ascending order.
    • Step 2: Record the frequency for each class interval.
    • Step 3: Calculate cumulative frequency by adding each frequency to the running total.
    • Step 4: The final cumulative frequency equals the total number of observations $N$.
  • Example Calculation: For intervals $1-10$ (freq=3), $11-20$ (freq=4), $21-30$ (freq=7), $31-40$ (freq=9), $41-50$ (freq=5), $51-60$ (freq=2):
    • Cumulative frequencies: $3, 7, 14, 23, 28, 30$
    • Total observations: $N = 30$

How do we determine class boundaries? Class boundaries are the true continuous limits of a class interval, calculated by finding the midpoint between the upper limit of one class and the lower limit of the next:

  • Lower Class Boundary: Subtract 0.5 from the lower class limit: $\text{LCB} = \text{Lower Limit} - 0.5$
  • Upper Class Boundary: Add 0.5 to the upper class limit: $\text{UCB} = \text{Upper Limit} + 0.5$
  • Example: For interval $51-60$, LCB = $51 - 0.5 = 50.5$ and UCB = $60 + 0.5 = 60.5$
  • Class Width: The difference between upper and lower class boundaries: $\text{Width} = \text{UCB} - \text{LCB}$

How do we locate specific data positions? Using the cumulative frequency column to pinpoint where specific ranked elements reside:

  • If cumulative frequency reaches $7$ at the end of $11-20$ interval and $14$ at $21-30$ interval, then the $8^{\text{th}}$ item lies in the $21-30$ interval.
  • This method helps locate median position, quartile positions, and percentile positions.

What are quartiles and percentile ranks? Quartiles divide a data set into four equal parts using three cut-off markers:

  • $Q_1$ (First/Lower Quartile): The $25^{\text{th}}$ percentile. Exactly $25\%$ of observations fall at or below this value. Position formula: $\text{Position of } Q_1 = \frac{N+1}{4}$
  • $Q_2$ (Second Quartile/Median): The $50^{\text{th}}$ percentile. Splits the data exactly in half. Position formula: $\text{Position of } Q_2 = \frac{N+1}{2}$
  • $Q_3$ (Third/Upper Quartile): The $75^{\text{th}}$ percentile. $75\%$ of data sits at or below, leaving top $25\%$ above. Position formula: $\text{Position of } Q_3 = \frac{3(N+1)}{4}$
  • Percentile Interpretation: A student at the $75^{\text{th}}$ percentile outperformed $75\%$ of peers and placed in the top quarter of performers.

How do we calculate the Interquartile Range (IQR)? The IQR measures statistical dispersion by focusing exclusively on the middle $50\%$ of data:

  • Formula: $\text{IQR} = Q_3 - Q_1$
  • Advantages over Standard Range: The IQR is robust against extreme outliers because it ignores the lowest $25\%$ and highest $25\%$ of values.
  • Example - Housing Market: If $Q_1 = \text{Rs. } 20,000,000$ and $Q_3 = \text{Rs. } 30,000,000$, then: $$\text{IQR} = 30,000,000 - 20,000,000 = \text{Rs. } 10,000,000$$ This means the middle $50\%$ of house prices span Rs. 10 million.
  • Outlier Detection: Values below $Q_1 - 1.5 \times \text{IQR}$ or above $Q_3 + 1.5 \times \text{IQR}$ are typically considered outliers.

How do we construct a complete cumulative frequency table?

  • Step 1: Create columns for: Class Interval, Frequency ($f$), Cumulative Frequency ($cf$)
  • Step 2: Fill class intervals in ascending order
  • Step 3: Enter frequencies for each class
  • Step 4: Calculate $cf$ values by cumulative addition
  • Step 5: Verify final $cf = N$ (total number of observations)

How do we interpret quartiles in real-world contexts?

  • Education: Test scores quartiles identify top performers ($Q_3$), average students ($Q_2$), and struggling students ($Q_1$).
  • Business: Sales data quartiles help identify top-performing products and regions.
  • Healthcare: Patient recovery times quartiles identify normal and unusual recovery patterns.
