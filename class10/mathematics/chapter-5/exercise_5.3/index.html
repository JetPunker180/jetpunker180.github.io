How do we solve equations containing rational expressions and identify extraneous solutions? A rational equation is an equation containing one or more rational expressions. To solve it, multiply every term by the least common denominator (LCD) to eliminate fractions, converting it into a standard linear or quadratic equation.

Example: $\frac{6x}{x-11} + 1 = \frac{3}{x-11}$

  1. Multiply through by $(x-11)$: $6x + (x-11) = 3$
  2. Simplify: $7x - 11 = 3$ → $7x = 14$ → $x = 2$
  3. Check: $x=2$ does not make denominator zero → valid solution

Extraneous Solutions: Any solution must be checked against domain constraints. If a value makes any original denominator equal to zero, it is extraneous and must be rejected.

Example of Extraneous: If solving yields $x=11$ and a denominator is $(x-11)$, then $x=11$ is extraneous (rejected).

Rate-of-Work Problems:

If Wasi takes $w$ hours and Waqar takes $w+9$ hours, working together they finish in 20 hours:

  • Individual rates: $\frac{1}{w}$ and $\frac{1}{w+9}$
  • Combined rate equation: $\frac{1}{w} + \frac{1}{w+9} = \frac{1}{20}$
  • Multiply by LCD $20w(w+9)$: $20(w+9) + 20w = w(w+9)$
  • $20w + 180 + 20w = w^2 + 9w$ → $w^2 - 31w - 180 = 0$
  • Solve quadratic to find individual times (discard negative roots)

Mixture Problems: Use fractional proportions to determine final solution percentages.
