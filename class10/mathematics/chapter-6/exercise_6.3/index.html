How do we geometrically validate functions and sketch non-linear rational profiles? Coordinate graphing bridges algebraic equations and spatial logic. Exercise 6.3 focuses on visual function verification using the vertical line test, alongside advanced curve-sketching methodologies for fractions.

The Vertical Line Test: To verify if a coordinate plot represents a valid single-valued function, draw vertical lines across the plane. If any vertical line intersects the curve at more than one point, the graph fails the test and represents a multi-mapped relation rather than a function.

  • ✅ Standard vertical parabola → passes (function)
  • ❌ Circle or sideways parabola → fails (not a function)

Asymptotes of Rational Functions: For $y = \frac{1}{x-1}$:

Vertical Asymptote: Occurs where the denominator equals zero.

  • $x-1 = 0$ → $x = 1$ (vertical asymptote)
  • The graph never crosses this line.

Horizontal Asymptote: Compare degrees of numerator and denominator.

  • Numerator degree = 0 (constant)
  • Denominator degree = 1 (linear)
  • Since degree of numerator < degree of denominator → $y = 0$ (horizontal asymptote)

Plotting Key Points:

  • y-intercept ($x=0$): $y = \frac{1}{0-1} = -1$ → $(0, -1)$
  • Neighborhood point ($x=2$): $y = \frac{1}{2-1} = 1$ → $(2, 1)$
  • Use these points to sketch the hyperbolic curve

Important Rule: A rational graph can never cross its vertical asymptote. The curve approaches the asymptote infinitely close but never touches or crosses it.
