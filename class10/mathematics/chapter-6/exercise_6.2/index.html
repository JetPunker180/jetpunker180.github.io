How do we combine functions using arithmetic operations? Functions can be manipulated algebraically using addition, subtraction, multiplication, and division.

Addition and Subtraction:

  • $(f+g)(x) = f(x) + g(x)$
  • $(f-g)(x) = f(x) - g(x)$

Example: $f(x) = 4(x-1) = 4x - 4$, $g(x) = x^2 - 2x + 1$

  • $(f+g)(x) = (4x - 4) + (x^2 - 2x + 1) = x^2 + 2x - 3$
  • $(f-g)(x) = (4x - 4) - (x^2 - 2x + 1) = 4x - 4 - x^2 + 2x - 1 = -x^2 + 6x - 5$

Inverse Function Derivation: To find $f^{-1}(x)$, swap $x$ and $y$ in $y = f(x)$, then solve for $y$.

Example 1 - Square Root Inverse: $g(x) = (x-3)^2$ with $x \ge 3$

  1. Set $y = (x-3)^2$
  2. Swap: $x = (y-3)^2$
  3. Solve: $\sqrt{x} = y-3$ (positive since $x \ge 3$)
  4. $g^{-1}(x) = 3 + \sqrt{x}$ for $x \ge 0$

Example 2 - Rational Inverse: $f(x) = \frac{3}{x-5}$

  1. Set $y = \frac{3}{x-5}$
  2. Swap: $x = \frac{3}{y-5}$
  3. Solve: $x(y-5) = 3$ → $y-5 = \frac{3}{x}$ → $f^{-1}(x) = \frac{3}{x} + 5$
  4. $f^{-1}(1) = \frac{3}{1} + 5 = 8$

Important Note: When subtracting functions, distribute the negative sign across all terms of the subtrahend polynomial.
