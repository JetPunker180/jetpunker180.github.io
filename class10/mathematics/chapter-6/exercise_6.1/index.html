How do we determine if a binary relation constitutes a valid mathematical function? A relation $R$ from set $A$ to set $B$ is a valid function if and only if:

  1. The domain of the relation must be exactly equal to the source set ($\text{dom } R = A$)
  2. There must be no repetition among the first elements of the ordered pairs (each input maps to exactly one unique output)

Example - Valid Function: Given $A=\{2,4,6,8\}$ and $B=\{1,3,5\}$, $R_1=\{(2,3),(6,5),(8,3),(4,1)\}$ is a function because $\text{dom } R_1 = A$ and every input has exactly one output.

Example - Not a Function: If an element maps to multiple outputs (e.g., input $6$ maps to both $1$ and $5$) or if an element from the source set is omitted, the relation fails to be a function.

Injective (One-to-One) Function: A function $f: A \rightarrow B$ is injective if distinct elements of the domain produce distinct images in the codomain: $f(x_1) = f(x_2) \Rightarrow x_1 = x_2$.

Solving for Unknown Parameters: Given $f(x) = t - ax$, with $f(1)=0$ and $f(-1)=2$:

  • $f(1) = t - a = 0$
  • $f(-1) = t + a = 2$
  • Solving: $a = 1$, $t = 1$
