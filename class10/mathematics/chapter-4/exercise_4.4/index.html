How do we find the solution to a system of linear inequalities? A system of linear inequalities consists of two or more inequalities that must be satisfied simultaneously. The solution to the system is the overlapping region (or intersection) where all individual inequality shaded regions meet. This region is often called the feasible region.

Graphing Systems of Inequalities:

  1. Individual Plotting: Graph each inequality as if it were a separate problem.
  2. Boundary Lines: Use dashed lines for strict inequalities ($<$, $>$) and solid lines for inclusive inequalities ($\le$, $\ge$).
  3. Shading: Shade the half-plane corresponding to each inequality.
  4. Intersection Analysis: The final solution is exclusively the area where the shadings overlap.

Non-negativity Constraints: For physical quantities (items, dimensions), always include $x \ge 0$ and $y \ge 0$ in the system.

Real-World Modeling - Budget Example:

If pizzas cost $15 each and sodas cost $2 each with a budget of $200:

  • $15x + 2y \le 200$ (budget constraint)
  • $x \ge 0$, $y \ge 0$ (non-negativity)
  • Also may have minimum quantity requirements like $x \ge 5$

Example System:

$$\begin{cases} x + y \le 6 \\ x \ge 0 \\ y \ge 0 \\ x \le 4 \end{cases}$$

Graph each inequality, shade appropriately, and find the overlapping region.

Steps to Solve System of Linear Inequalities:

  1. Rewrite each inequality in slope-intercept form ($y = mx + b$) if needed
  2. Graph each boundary line (solid or dashed)
  3. Shade the appropriate half-plane for each inequality
  4. Identify the overlapping shaded region
  5. The feasible region is the solution set
