How do we determine if an ordered pair is a solution to a two-variable linear inequality? An ordered pair $(x, y)$ is a solution if substituting those values into the inequality results in a true mathematical statement.

Example 1: Test $(0,0)$ in $x + y < -4$: $0 + 0 < -4$ → $0 < -4$ is false. Therefore, $(0,0)$ is not a solution.

Example 2: Test $(-2,-3)$ in $y - x > -2$: $-3 - (-2) > -2$ → $-3 + 2 > -2$ → $-1 > -2$ is true. Therefore, $(-2,-3)$ is a solution.

Graphing Two-Variable Linear Inequalities:

  1. Rewrite the inequality in slope-intercept form ($y = mx + b$ or similar) to identify the boundary line.
  2. Determine the line style:
    • Solid line: for $\le$ or $\ge$ (points on the line are included)
    • Dashed line: for $<$ or $>$ (points on the line are excluded)
  3. Determine shading direction:
    • $y > mx + b$ → shade above the line
    • $y < mx + b$ → shade below the line
  4. Use a test point like $(0,0)$ to verify the correct half-plane.

Example - Graphing $y > 2x - 3$:

  • Boundary line: $y = 2x - 3$ (dashed because $>$)
  • Shade above the line (since $y >$)
  • Test $(0,0)$: $0 > 2(0)-3$ → $0 > -3$ true → confirm shading above
