How do we solve equations and inequalities involving absolute values? The absolute value $|x|$ represents the distance of $x$ from zero on the number line.

Absolute Value Equations $|ax+b| = c$:

  • Case 1: $ax+b = c$
  • Case 2: $ax+b = -c$
  • Solve both equations to find the complete solution set.

Example: $|2x-3| = 5$ → $2x-3 = 5$ → $x = 4$; $2x-3 = -5$ → $x = -1$ → Solution set: $\{4, -1\}$

Absolute Value Inequalities $|ax+b| \le c$:

  • Translates to compound inequality: $-c \le ax+b \le c$
  • Represents a bounded solution set (concentrated toward the center)

Example: $|x-3| \le 4$ → $-4 \le x-3 \le 4$ → $ -1 \le x \le 7$

Absolute Value Inequalities $|ax+b| \ge c$:

  • Translates to two disjoint scenarios: $ax+b \ge c$ OR $ax+b \le -c$
  • Represents an outward solution set (moving away from the center)

Example: $|x-3| \ge 4$ → $x-3 \ge 4$ OR $x-3 \le -4$ → $x \ge 7$ OR $x \le -1$

Modeling Real-World Deviation: An essay contest requires 500 words with a deviation of at most 30 words: $|x - 500| \le 30$ → $500-30 \le x \le 500+30$ → $470 \le x \le 530$.

Number Line Graphing:

  • $\le$ or $\ge$: closed circles (●) for included endpoints
  • $<$ or $>$: open circles (○) for excluded endpoints
  • Shading indicates the solution interval
