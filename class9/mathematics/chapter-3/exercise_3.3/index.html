What are Cartesian products and binary relations? Exercise 3.3, "Cartesian Products and Binary Relations," introduces the fundamental concept of pairing elements between sets to form ordered pairs.

What is an ordered pair? An ordered pair $(a, b)$ consists of two elements where order matters: $(a, b) \neq (b, a)$ unless $a = b$. The first component comes from the first set, and the second component comes from the second set.

How do we solve for unknowns in equal ordered pairs? If $(x + 2, y - 3) = (5, 7)$, then:

  • $x + 2 = 5 \implies x = 3$
  • $y - 3 = 7 \implies y = 10$
  • Equate corresponding first and second components

What is the Cartesian product of sets? The Cartesian product $A \times B$ is the set of all ordered pairs $(a, b)$ where $a \in A$ and $b \in B$.

  • $A \times B = \{(a, b) : a \in A \text{ and } b \in B\}$
  • $B \times A = \{(b, a) : b \in B \text{ and } a \in A\}$
  • $A \times A = \{(a_1, a_2) : a_1, a_2 \in A\}$

What is the formula for number of elements in Cartesian product?

  • $n(A \times B) = n(A) \times n(B)$
  • If $n(A) = 3$ and $n(B) = 4$, then $n(A \times B) = 3 \times 4 = 12$
  • The number of arrows in an arrow diagram equals the product of the number of elements in both sets

Is Cartesian product commutative? No! $A \times B \neq B \times A$ (non-commutative property). The ordered pairs are reversed.

What are the distributive laws of Cartesian product?

  • Over union: $A \times (B \cup C) = (A \times B) \cup (A \times C)$
  • Over intersection: $A \times (B \cap C) = (A \times B) \cap (A \times C)$
  • Over set difference: $A \times (B - C) = (A \times B) - (A \times C)$

Example - Distributive law over union: Let $A = \{1, 2\}$, $B = \{a, b\}$, $C = \{b, c\}$

  • LHS: $B \cup C = \{a, b, c\}$, $A \times (B \cup C) = \{(1,a), (1,b), (1,c), (2,a), (2,b), (2,c)\}$
  • RHS: $A \times B = \{(1,a), (1,b), (2,a), (2,b)\}$, $A \times C = \{(1,b), (1,c), (2,b), (2,c)\}$
  • $(A \times B) \cup (A \times C) = \{(1,a), (1,b), (1,c), (2,a), (2,b), (2,c)\}$
  • LHS = RHS ✓

How do we represent Cartesian products visually?

Method 1 - Coordinate Plane (Graphical Method):

  • Plot the first set elements on the x-axis (horizontal)
  • Plot the second set elements on the y-axis (vertical)
  • Mark points at the intersection of each pair
  • Example: $A = \{1, 2\}$, $B = \{a, b\}$ - plot points at (1,a), (1,b), (2,a), (2,b)

Method 2 - Arrow Diagram:

  • Draw set A as one column of dots
  • Draw set B as another column of dots
  • Draw arrows from each element in A to each element in B
  • Number of arrows = $n(A) \times n(B)$

Important properties to remember:

  • $(a, b) = (c, d)$ if and only if $a = c$ and $b = d$
  • $n(A \times B) = n(A) \times n(B)$
  • $A \times \emptyset = \emptyset$ and $\emptyset \times B = \emptyset$
  • $A \times (B \cup C) = (A \times B) \cup (A \times C)$
  • $A \times (B \cap C) = (A \times B) \cap (A \times C)$
  • $A \times (B - C) = (A \times B) - (A \times C)$
  • $A \times B \neq B \times A$ (unless $A = B$ or one set is empty)
