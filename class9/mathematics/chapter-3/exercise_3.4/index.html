What are binary relations? Exercise 3.4, "Binary Relations, Domain, and Range," explores the subsets of Cartesian products and their mathematical properties. A binary relation from set A to set B is any subset of $A \times B$.

How do we calculate the total number of binary relations? The total number of binary relations possible between sets A and B is:

  • $n(A \times B) = n(A) \times n(B)$
  • Total relations = $2^{n(A \times B)} = 2^{n(A) \times n(B)}$
  • Example: If $n(A) = 2$ and $n(B) = 3$, then total relations = $2^{2 \times 3} = 2^6 = 64$

How do we write relations in tabular form? You will learn to write relations based on specific conditions:

  • "Is equal to": $R = \{(a,b) : a = b\}$
  • "Is less than": $R = \{(a,b) : a < b\}$
  • Algebraic equations: $R = \{(x,y) : y = 2x + 1\}$ where $x \in A$, $y \in B$
  • "Is factor of": $R = \{(a,b) : a \text{ divides } b\}$
  • "Is multiple of": $R = \{(a,b) : a \text{ is multiple of } b\}$

What is domain and range of a relation?

  • Domain: The set of all first elements of ordered pairs in $R$, denoted $Dom(R)$
  • Range: The set of all second elements of ordered pairs in $R$, denoted $Ran(R)$
  • Example: If $R = \{(1,2), (1,3), (2,4)\}$, then $Dom(R) = \{1,2\}$, $Ran(R) = \{2,3,4\}$

What is an inverse relation ($R^{-1}$)? The inverse relation $R^{-1}$ is formed by swapping the components of each ordered pair in $R$:

  • If $R = \{(a,b) : (a,b) \in A \times B\}$, then $R^{-1} = \{(b,a) : (b,a) \in B \times A\}$
  • $Dom(R^{-1}) = Ran(R)$ and $Ran(R^{-1}) = Dom(R)$
  • Example: If $R = \{(1,2), (1,3), (2,4)\}$, then $R^{-1} = \{(2,1), (3,1), (4,2)\}$

How do we convert set-builder forms for inverse relations? When a relation is defined by an equation, swap $x$ and $y$ to get the inverse:

  • If $R = \{(x,y) : x - y = 2\}$, then $R^{-1} = \{(x,y) : y - x = 2\}$ or $\{(x,y) : x - y = -2\}$
  • If $R = \{(x,y) : y = 2x + 1\}$, then $R^{-1} = \{(x,y) : x = 2y + 1\}$ or $\{(x,y) : y = \frac{x-1}{2}\}$

How do we represent relations using arrow diagrams?

  • Draw set A as one column of dots (domain)
  • Draw set B as another column of dots (range)
  • Draw arrows from each element in A to its corresponding element(s) in B
  • For inverse relation $R^{-1}$, reverse the direction of all arrows

Example - Finding domain and range from condition: Let $A = \{1,2,3,4\}$, $B = \{1,2,3,4,5,6\}$, and $R = \{(a,b) : a \text{ divides } b\}$

  • $R = \{(1,1), (1,2), (1,3), (1,4), (1,5), (1,6), (2,2), (2,4), (2,6), (3,3), (3,6), (4,4)\}$
  • $Dom(R) = \{1,2,3,4\}$
  • $Ran(R) = \{1,2,3,4,5,6\}$

Example - Number of relations: If $n(A) = 4$ and $n(B) = 3$, total binary relations from A to B = $2^{4 \times 3} = 2^{12} = 4096$

Key properties to remember:

  • A relation is any subset of $A \times B$ (including empty set and whole set)
  • Domain of $R$ = Range of $R^{-1}$
  • Range of $R$ = Domain of $R^{-1}$
  • $(R^{-1})^{-1} = R$
  • The arrow diagram for $R^{-1}$ is the reversal of arrows in $R$
