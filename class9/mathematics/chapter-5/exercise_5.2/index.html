What are radical equations? A radical equation is an equation in which the variable appears inside a square root (radical) or other root. The most common type involves square roots.

How do we solve radical equations? The general method is to isolate the radical term on one side, then square both sides to eliminate the square root.

Example 1 - Simple radical equation: Solve $\sqrt{2x} = 4$

  • Isolate radical: Already isolated on LHS
  • Square both sides: $(\sqrt{2x})^2 = (4)^2$
  • $2x = 16$
  • $x = 8$
  • Check: $\sqrt{2 \times 8} = \sqrt{16} = 4$ ✓

What if the isolated radical equals a negative number? Since the principal square root of a real number is always non-negative (≥ 0), an equation like $\sqrt{3x-5} = -10$ has no real solution.

  • Reason: $\sqrt{\text{anything}} \geq 0$, cannot equal $-10$
  • Solution set: $\phi$ (empty set)
  • No need to square both sides - recognize immediately

How do we solve radical equations with radicals on both sides? When both sides contain square roots, square both sides directly.

  • Example: $\sqrt{5t-2} = \sqrt{3t+4}$
  • Square both sides: $(\sqrt{5t-2})^2 = (\sqrt{3t+4})^2$
  • $5t-2 = 3t+4$
  • $2t = 6$ → $t = 3$
  • Check: LHS $= \sqrt{5(3)-2} = \sqrt{15-2} = \sqrt{13}$, RHS $= \sqrt{3(3)+4} = \sqrt{9+4} = \sqrt{13}$ ✓

How do we solve radical equations with the variable inside two different radicals? Isolate one radical, square both sides, then handle the remaining radical.

  • Example: $\sqrt{x+3} + \sqrt{x} = 3$
  • Isolate one radical: $\sqrt{x+3} = 3 - \sqrt{x}$
  • Square both sides: $x+3 = 9 - 6\sqrt{x} + x$
  • Simplify: $3 = 9 - 6\sqrt{x}$
  • $-6 = -6\sqrt{x}$ → $\sqrt{x} = 1$
  • Square: $x = 1$
  • Check: $\sqrt{1+3} + \sqrt{1} = \sqrt{4} + 1 = 2 + 1 = 3$ ✓

How do we solve fractional radical equations? Square both sides first to remove radicals, then use cross-multiplication.

  • Example: $\sqrt{\frac{a+6}{a+2}} = \sqrt{\frac{a+2}{a-1}}$
  • Square both sides: $\frac{a+6}{a+2} = \frac{a+2}{a-1}$
  • Cross-multiply: $(a+6)(a-1) = (a+2)^2$
  • Expand: $a^2 + 5a - 6 = a^2 + 4a + 4$
  • Simplify: $5a - 6 = 4a + 4$ → $a = 10$
  • Check original equation with $a = 10$

What are extraneous solutions? When we square both sides of an equation, we may introduce solutions that do NOT satisfy the original equation. These are called extraneous solutions.

  • Why they occur: Squaring can turn a false statement (e.g., $-2 = 2$) into a true statement (e.g., $4 = 4$)
  • How to identify: Always substitute your solutions back into the original equation
  • Invalid conditions: If substitution gives a square root of a negative number, or if LHS ≠ RHS, reject the solution

Example - Extraneous solution: Solve $\sqrt{x+2} = x$

  • Square both sides: $x+2 = x^2$
  • Rearrange: $x^2 - x - 2 = 0$
  • Factor: $(x-2)(x+1) = 0$ → $x = 2$ or $x = -1$
  • Check $x = 2$: $\sqrt{2+2} = \sqrt{4} = 2$ → $2 = 2$ ✓ Valid
  • Check $x = -1$: $\sqrt{-1+2} = \sqrt{1} = 1$, but RHS $= -1$ → $1 = -1$ ✗ Extraneous
  • Solution set: $\{2\}$ only

What is the radicand condition? The expression inside a square root (the radicand) must be non-negative for real number solutions.

  • For $\sqrt{f(x)}$, we require $f(x) \geq 0$
  • When solving, check that your solution makes all radicands non-negative

Key steps for solving radical equations:

  • Step 1: Isolate one radical term on one side of the equation
  • Step 2: Square both sides of the equation
  • Step 3: If a radical remains, repeat steps 1-2
  • Step 4: Solve the resulting equation
  • Step 5: Check all solutions in the original equation for extraneous solutions
