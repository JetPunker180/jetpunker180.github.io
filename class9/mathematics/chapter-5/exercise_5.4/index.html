What is a linear inequality? A linear inequality is a mathematical statement that compares two linear expressions using inequality symbols: $<$ (less than), $>$ (greater than), $\leq$ (less than or equal to), or $\geq$ (greater than or equal to).

How do we check if a value satisfies an inequality? Substitute the given variable value into the expression. If the resulting statement is true, the value satisfies the inequality.

  • Example: Check $y = 3$ in $5y - 12 > 0$
  • $5(3) - 12 = 15 - 12 = 3$
  • $3 > 0$ is TRUE → $y = 3$ satisfies the inequality

What is the sign reversal rule for inequalities? When you multiply or divide both sides of an inequality by a negative number, you must reverse the inequality symbol.

  • Example: $-3x < 6$
  • Divide both sides by $-3$ (negative number) → flip $<$ to $>$
  • $x > -2$
  • Check: If $x = 0$, LHS of original: $-3(0) = 0 < 6$ ✓

How do we solve multi-step linear inequalities? Use inverse operations (same as solving equations) while following the sign reversal rule.

  • Example: $3x + 7 \leq 2x - 5$
  • Subtract $2x$: $x + 7 \leq -5$
  • Subtract $7$: $x \leq -12$

How do we represent solutions for different number sets?

  • Natural numbers ($\mathbb{N}$): $\{1, 2, 3, 4, 5, ...\}$ (positive integers, start from 1)
  • Whole numbers ($\mathbb{W}$): $\{0, 1, 2, 3, 4, 5, ...\}$ (include 0)
  • Integers ($\mathbb{Z}$): $\{..., -3, -2, -1, 0, 1, 2, 3, ...\}$
  • Real numbers ($\mathbb{R}$): Use set-builder notation $\{x | x \in \mathbb{R} \wedge x \leq -3\}$ or interval notation $(-\infty, -3]$

Example - Solution set for $x \leq 5$ where $x \in \mathbb{W}$: $\{0, 1, 2, 3, 4, 5\}$

Example - Solution set for $z \leq -3$ where $z \in \mathbb{R}$: $\{z | z \in \mathbb{R} \wedge z \leq -3\}$ or $(-\infty, -3]$

How do we solve compound inequalities with 'or'? For 'or', find the union of the separate solution sets. The solution satisfies at least one condition.

  • Example: $x > -2$ or $x < -6$
  • Solution set: $(-\infty, -6) \cup (-2, \infty)$
  • All numbers except those between $-6$ and $-2$ (inclusive?)

How do we solve compound inequalities with 'and'? For 'and', find the intersection where both conditions are met simultaneously. Often written as a chain inequality.

  • Example: $x > -1$ and $x \leq 3$
  • Chain notation: $-1 < x \leq 3$
  • Solution set: $(-1, 3]$

How do we solve word problems involving inequalities? Translate verbal phrases into algebraic inequalities, then solve.

Example - Word problem: "Two times a number decreased by 5 is greater than or equal to the number increased by 8."

  • Let the number be $x$
  • "Two times a number decreased by 5" → $2x - 5$
  • "is greater than or equal to" → $\geq$
  • "the number increased by 8" → $x + 8$
  • Inequality: $2x - 5 \geq x + 8$
  • Subtract $x$: $x - 5 \geq 8$
  • Add $5$: $x \geq 13$

Key rules for inequalities:

  • Adding or subtracting the same number from both sides does NOT change the inequality direction
  • Multiplying or dividing by a positive number does NOT change the direction
  • Multiplying or dividing by a negative number DOES change the direction (flip $<$ to $>$, $\leq$ to $\geq$, etc.)
  • Never multiply or divide by a variable unless you know its sign

Common mistakes to avoid:

  • Forgetting to reverse the inequality sign when multiplying/dividing by a negative number
  • Confusing 'and' (intersection) with 'or' (union) in compound inequalities
  • Writing chain inequalities in the wrong order (must be consistent, e.g., $-1 < x \leq 3$ not $x > -1 \leq 3$)
