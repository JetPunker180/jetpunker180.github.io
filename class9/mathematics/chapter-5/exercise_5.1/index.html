What are linear equations in one variable? A linear equation in one variable is an equation that can be written in the form $ax + b = 0$, where $a \neq 0$, and the highest power of the variable is 1.

How do we solve linear equations with integer coefficients? Combine like terms and isolate the variable by moving all variable terms to one side and constants to the other.

  • Example: $5x - 2 - x = 4 - 3x - 27$
  • Simplify LHS: $5x - x - 2 = 4x - 2$
  • Simplify RHS: $4 - 27 - 3x = -23 - 3x$
  • Equation: $4x - 2 = -23 - 3x$
  • Add $3x$ to both sides: $7x - 2 = -23$
  • Add $2$ to both sides: $7x = -21$
  • Divide by $7$: $x = -3$

How do we solve equations with fractional coefficients? Identify the Least Common Multiple (LCM) of all denominators and multiply every term by this LCM to clear fractions.

  • Example: $\frac{x-2}{2} + \frac{x+10}{9} = 5$
  • LCM of $2$ and $9$ is $18$
  • Multiply every term by $18$: $18 \times \frac{x-2}{2} + 18 \times \frac{x+10}{9} = 18 \times 5$
  • Simplify: $9(x-2) + 2(x+10) = 90$
  • Expand: $9x - 18 + 2x + 20 = 90$
  • Combine: $11x + 2 = 90$
  • $11x = 88$ → $x = 8$

How do we solve equations with decimals? Group like decimal terms, then add or subtract to isolate the variable.

  • Example: $0.5x = 6.3 - 0.2x$
  • Add $0.2x$ to both sides: $0.5x + 0.2x = 6.3$
  • $0.7x = 6.3$
  • Divide by $0.7$: $x = 9$

How do we solve equations with variables in the denominator? Find a common denominator involving the variable, multiply every term by it, and note the condition that the variable cannot make any denominator zero.

  • Example: $\frac{5}{6y} + \frac{3}{4y} = \frac{7}{12y} + \frac{1}{3}$
  • Common denominator: $12y$ (with condition $y \neq 0$)
  • Multiply every term by $12y$: $12y \times \frac{5}{6y} + 12y \times \frac{3}{4y} = 12y \times \frac{7}{12y} + 12y \times \frac{1}{3}$
  • Simplify: $10 + 9 = 7 + 4y$
  • $19 = 7 + 4y$ → $12 = 4y$ → $y = 3$
  • Check: $y \neq 0$, so $y = 3$ is valid

What are the properties of equality used in solving linear equations?

  • Addition Property: If $a = b$, then $a + c = b + c$
  • Subtraction Property: If $a = b$, then $a - c = b - c$
  • Multiplication Property: If $a = b$, then $ac = bc$
  • Division Property: If $a = b$ and $c \neq 0$, then $a/c = b/c$

Example - Combining like terms with variables on both sides: $4a - 15a + 42 = 35 + 5a - 9$

  • Simplify LHS: $4a - 15a = -11a$, so $-11a + 42$
  • Simplify RHS: $35 - 9 = 26$, so $26 + 5a$
  • Equation: $-11a + 42 = 26 + 5a$
  • Subtract $5a$: $-16a + 42 = 26$
  • Subtract $42$: $-16a = -16$
  • Divide by $-16$: $a = 1$

Important note about clearing denominators: When multiplying an equation by the LCM to clear fractions, multiply EVERY term (including constants on both sides) by the LCM. Common mistake: forgetting to multiply constant terms.

Checking for extraneous solutions: When variables appear in denominators, always check that your solution does not make any denominator zero. These are called extraneous solutions and must be rejected.
