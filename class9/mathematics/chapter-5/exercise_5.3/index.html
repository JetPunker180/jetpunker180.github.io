What is absolute value? The absolute value of a number $x$, denoted $|x|$, represents its distance from zero on the number line. It is always non-negative: $|x| \geq 0$ for all real $x$.

How do we solve basic absolute value equations? Apply the property: if $|x| = a$ where $a > 0$, then $x = a$ or $x = -a$.

  • Example: $|x+2| = 6$
  • Case 1: $x+2 = 6$ → $x = 4$
  • Case 2: $x+2 = -6$ → $x = -8$
  • Solution set: $\{4, -8\}$

What if the absolute value equals zero? Since zero has no sign, solve the inner expression once.

  • Example: $|6-3y| = 0$
  • Solve $6-3y = 0$ → $y = 2$
  • Solution set: $\{2\}$

How do we isolate absolute value before splitting into cases? When there are constants outside the absolute value bars, isolate the absolute value term first.

  • Example: $3|z-2| - 4 = -2$
  • Add $4$ to both sides: $3|z-2| = 2$
  • Divide by $3$: $|z-2| = \frac{2}{3}$
  • Now split: $z-2 = \frac{2}{3}$ or $z-2 = -\frac{2}{3}$
  • $z = \frac{8}{3}$ or $z = \frac{4}{3}$

How do we recognize equations with no solution? Since absolute value is always non-negative, if an isolated absolute value equals a negative number, there is no real solution.

  • Example: $|5x| = -5$
  • LHS $\geq 0$, RHS $= -5 < 0$ → impossible
  • Solution set: $\phi$ (empty set)
  • Do NOT split into cases - recognize immediately!

How do we solve equations with absolute values on both sides? Use the property: $|a| = |b| \iff a = b$ or $a = -b$.

  • Example: $|5x-3| = |x+7|$
  • Case 1: $5x-3 = x+7$ → $4x = 10$ → $x = 2.5$
  • Case 2: $5x-3 = -(x+7)$ → $5x-3 = -x-7$ → $6x = -4$ → $x = -\frac{2}{3}$
  • Solution set: $\{2.5, -\frac{2}{3}\}$

How do we solve equations with coefficients outside the absolute value bars on both sides? Isolate the absolute value expressions, then apply the $|a| = |b| \iff a = \pm b$ rule.

  • Example: $3|x+1| = 2|2x-1|$
  • Divide both sides by $2$: $\frac{3}{2}|x+1| = |2x-1|$
  • This is $|2x-1| = \frac{3}{2}|x+1|$
  • Better approach: Square both sides or use case analysis
  • Alternatively, use $|a| = |b| \iff a = \pm b$ after ensuring coefficients are 1
  • Case 1: $3(x+1) = 2(2x-1)$ → $3x+3 = 4x-2$ → $x = 5$
  • Case 2: $3(x+1) = -2(2x-1)$ → $3x+3 = -4x+2$ → $7x = -1$ → $x = -\frac{1}{7}$
  • Solution set: $\{5, -\frac{1}{7}\}$

What is the step-by-step method for solving absolute value equations?

  • Step 1: Isolate the absolute value expression on one side of the equation
  • Step 2: If the isolated absolute value equals a negative number → no solution ($\phi$)
  • Step 3: If it equals zero → solve the inner expression = 0
  • Step 4: If it equals a positive number → split into two cases: inner = positive AND inner = negative
  • Step 5: If absolute values appear on both sides → use $|a| = |b| \iff a = b$ or $a = -b$
  • Step 6: Check all solutions in the original equation (though usually not necessary for absolute value equations, good practice)

Common mistake to avoid: Forgetting to isolate the absolute value before splitting into cases. In equations like $3|z-2| - 4 = -2$, you must move the $-4$ and divide by $3$ first.

Absolute value vs squaring note: Another method is to square both sides, since $|a| = |b| \iff a^2 = b^2$. This works well but can create higher-degree equations.
