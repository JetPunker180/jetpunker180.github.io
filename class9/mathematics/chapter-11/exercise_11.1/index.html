What is a frequency distribution table? A frequency distribution organizes raw data into class intervals (groups) and shows how many data points fall into each interval.

  • Classes: Groups or intervals (e.g., $40-49$, $50-59$)
  • Frequency ($f$): Number of observations in each class
  • Cumulative Frequency ($cf$): Running total of frequencies

How do we calculate class parameters?

  • Class Mark (Midpoint): $x = \frac{\text{lower limit} + \text{upper limit}}{2}$
  • Example: Class $1-10$ → $x = (1+10)/2 = 5.5$
  • Class Size (Width): $h = \text{upper limit} - \text{lower limit} + 1$
  • Example: Class $1-10$ → $h = 10 - 1 + 1 = 10$

How do we calculate class boundaries for histograms? Class boundaries eliminate gaps between bars in a histogram.

  • Lower boundary = lower limit $- 0.5$
  • Upper boundary = upper limit $+ 0.5$
  • Example: Class $51-60$ → boundaries: $50.5$ to $60.5$

How do we calculate data percentages? Percentage = $\frac{\text{frequency}}{\text{total frequency}} \times 100\%$

  • Example: Frequency $= 7$, total $= 80$ → $\frac{7}{80} \times 100 = 8.75\%$

How do we construct a histogram? A histogram is a graphical representation of a frequency distribution using adjacent rectangles.

  • X-axis: Class boundaries (continuous, no gaps)
  • Y-axis: Frequencies
  • Bars: Adjacent rectangles (no spaces between bars)
  • Height of each bar = frequency of that class

How do we construct a frequency polygon? A frequency polygon is a line graph that can be drawn using class midpoints.

  • Plot points at $(x, f)$ where $x$ = class mark (midpoint), $f$ = frequency
  • Connect the points with straight lines in order
  • Can be drawn on top of a histogram or separately
  • Extend to both ends to touch the x-axis (add classes with zero frequency at ends)

How do we analyze graphical data? Identify trends and patterns:

  • Highest frequency → peak of histogram or polygon
  • Lowest frequency → lowest point
  • Example: In per-capita income graphs, the peak indicates the income range with the most states/countries

Example - Frequency Table Construction: Given data on student scores, construct a frequency table:

Important notes:

  • Before drawing a histogram, convert class limits to class boundaries to ensure no gaps
  • Class size must be consistent for histogram and frequency polygon
  • Cumulative frequency is useful for finding medians and percentiles
