What are measures of central tendency? Measures of central tendency are single values that describe the center or typical value of a dataset. The three main measures are mean, median, and mode.

How do we calculate arithmetic mean for ungrouped data?

  • Formula: $\bar{x} = \frac{\sum x}{n}$
  • Where $\sum x$ = sum of all values, $n$ = number of values
  • Example: Scores $5, 7, 9, 11$ → $\bar{x} = (5+7+9+11)/4 = 32/4 = 8$

How do we calculate arithmetic mean for grouped data?

  • Formula: $\bar{x} = \frac{\sum fx}{\sum f}$
  • Where $x$ = class mark (midpoint), $f$ = frequency
  • $x = \frac{\text{lower limit} + \text{upper limit}}{2}$
  • Example: Find class marks, multiply by frequencies, sum, divide by total frequency

How do we calculate weighted mean? Weighted mean accounts for varying importance (weights) of values.

  • Formula: $\bar{x}_w = \frac{\sum Wx}{\sum W}$
  • Where $W$ = weight, $x$ = value
  • Example: Subject marks with different credit hours → weighted average

How do we find the median for ungrouped data?

  • Step 1: Arrange data in ascending order
  • Step 2: If $n$ is odd, median = $(\frac{n+1}{2})^{\text{th}}$ term
  • Step 3: If $n$ is even, median = average of $(\frac{n}{2})^{\text{th}}$ and $(\frac{n}{2} + 1)^{\text{th}}$ terms
  • Example: $3, 5, 7, 9, 11$ (odd) → median = $7$
  • Example: $3, 5, 7, 9$ (even) → median = $(5+7)/2 = 6$

How do we find the median for grouped data?

  • Formula: $\text{Median} = l + \frac{h}{f} (\frac{n}{2} - c)$
  • Where:
    • $l$ = lower boundary of median class
    • $h$ = class size
    • $f$ = frequency of median class
    • $n$ = total frequency
    • $c$ = cumulative frequency before median class

How do we find the mode?

  • Mode = most frequently occurring value
  • Unimodal: One mode (e.g., $1,2,2,2,3,4$ → mode = $2$)
  • Bimodal: Two modes (e.g., $1,2,2,3,3,4$ → modes = $2$ and $3$)
  • No mode: All values appear once (e.g., $1,2,3,4,5$ → no mode)

How do we find the mode for grouped data?

  • Formula: $\text{Mode} = l + \frac{(f_m - f_1)}{2f_m - f_1 - f_2} \times h$
  • Where:
    • $l$ = lower boundary of modal class (class with highest frequency)
    • $h$ = class size
    • $f_m$ = frequency of modal class (maximum frequency)
    • $f_1$ = frequency of class before modal class
    • $f_2$ = frequency of class after modal class

Real-world application - Comparing performance: Calculate the mean score of two batsmen to determine who has a higher average and is therefore a better run-getter.

Important notes:

  • Always arrange data in ascending order before finding median
  • For grouped data median formula, ensure $l$ is the lower boundary (not lower limit)
  • For modal formula, identify $f_1$, $f_2$, and $f_m$ correctly
