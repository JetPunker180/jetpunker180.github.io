How do we find the shortest (perpendicular) distance from a point to a line? The perpendicular distance is the shortest distance between a point and a line.

  • Formula: $d = \frac{|Ax_1 + By_1 + C|}{\sqrt{A^2 + B^2}}$
  • Where $Ax + By + C = 0$ is the general form of the line
  • $(x_1, y_1)$ is the given point
  • The result is always non-negative (absolute value ensures positive distance)

How do we ensure the line is in general form? Before using the formula, convert the line equation to $Ax + By + C = 0$.

  • Example: $y = 2x + 3$ becomes $2x - y + 3 = 0$ (or $-2x + y - 3 = 0$)
  • Both forms work as long as $A$, $B$, $C$ are correctly identified

Example - Distance from point to line: Find distance from $P(2,3)$ to line $3x + 4y - 5 = 0$.

  • $A = 3$, $B = 4$, $C = -5$, $x_1 = 2$, $y_1 = 3$
  • $d = \frac{|3(2) + 4(3) - 5|}{\sqrt{3^2 + 4^2}} = \frac{|6 + 12 - 5|}{\sqrt{9 + 16}} = \frac{|13|}{\sqrt{25}} = \frac{13}{5} = 2.6$ units

How do we find the distance from the origin to a line? Since the origin is $(0,0)$, the formula simplifies:

  • $d = \frac{|A(0) + B(0) + C|}{\sqrt{A^2 + B^2}} = \frac{|C|}{\sqrt{A^2 + B^2}}$
  • Example: Distance from origin to line $3x + 4y - 10 = 0$ is $d = \frac{|-10|}{\sqrt{9+16}} = \frac{10}{5} = 2$ units

How do we find the distance between two parallel lines? For parallel lines $Ax + By + C_1 = 0$ and $Ax + By + C_2 = 0$:

  • $d = \frac{|C_1 - C_2|}{\sqrt{A^2 + B^2}}$
  • Important: Lines must be in the same form (same $A$ and $B$ coefficients)
  • If coefficients differ, multiply one equation to make $A$ and $B$ equal

Example - Distance between parallel lines: Find distance between $3x + 4y - 5 = 0$ and $3x + 4y + 10 = 0$.

  • $C_1 = -5$, $C_2 = 10$
  • $d = \frac{|-5 - 10|}{\sqrt{3^2 + 4^2}} = \frac{|-15|}{5} = \frac{15}{5} = 3$ units

Example - Parallel lines with different coefficients: Find distance between $6x + 8y - 10 = 0$ and $3x + 4y + 5 = 0$.

  • Divide first equation by 2: $3x + 4y - 5 = 0$
  • Second equation: $3x + 4y + 5 = 0$
  • $C_1 = -5$, $C_2 = 5$, $d = \frac{|-5 - 5|}{\sqrt{3^2+4^2}} = \frac{|-10|}{5} = 2$ units

How do we verify if a line is tangent to a circle? A line is tangent to a circle if the perpendicular distance from the circle's center to the line equals the circle's radius.

  • Step 1: Find center $(h,k)$ and radius $r$ of the circle
  • Step 2: Calculate distance $d$ from center to line using point-to-line formula
  • Step 3: If $d = r$, the line is tangent; if $d < r$, it intersects at two points; if $d > r$, no intersection

How do we calculate the altitude of a triangle? The altitude from a vertex is the perpendicular distance from that vertex to the opposite side.

  • Step 1: Find equation of the side (opposite side) in general form $Ax + By + C = 0$
  • Step 2: Apply point-to-line distance formula using the vertex coordinates

Example - Triangle altitude: For triangle $A(1,2)$, $B(4,6)$, $C(7,2)$, find altitude from $B$ to side $AC$.

  • Line $AC$ through $A(1,2)$ and $C(7,2)$: $y = 2$ → $0x + 1y - 2 = 0$
  • $A = 0$, $B = 1$, $C = -2$, point $B(4,6)$
  • $d = \frac{|0(4) + 1(6) - 2|}{\sqrt{0^2 + 1^2}} = \frac{|6 - 2|}{1} = 4$ units

How do we find the width of a path or height of a figure? Use the perpendicular distance formula between two lines (path boundaries) or between a point and a line (height).

Important note: Always convert the line equation to general form $Ax + By + C = 0$ before using the distance formula. Signs matter! Keep $C$ on the same side as $Ax + By$.
