What is the relationship between HCF and LCM of polynomials? Exercise 4.5, "Relationship between HCF and LCM," focuses on the fundamental algebraic identity that links two polynomials $P$ and $Q$ with their Highest Common Factor (HCF) and Least Common Multiple (LCM).

What is the fundamental formula? For any two polynomials $P$ and $Q$:

  • $P \times Q = \text{HCF} \times \text{LCM}$
  • This identity holds true for algebraic expressions (ignoring numerical constants)
  • Also written as: $\text{LCM} = \frac{P \times Q}{\text{HCF}}$ or $\text{HCF} = \frac{P \times Q}{\text{LCM}}$

How do we find the product of two polynomials from HCF and LCM? Simply multiply the given HCF and LCM:

  • $P \times Q = \text{HCF} \times \text{LCM}$
  • Example: If HCF = $(x - 1)$ and LCM = $(x - 1)(x + 1)(x^2 + 1)$, then $P \times Q = (x - 1) \times (x - 1)(x + 1)(x^2 + 1) = (x - 1)^2(x + 1)(x^2 + 1)$

How do we find unknown LCM or HCF? If the product $P \times Q$ is known and either HCF or LCM is given:

  • $\text{LCM} = \frac{P \times Q}{\text{HCF}}$
  • $\text{HCF} = \frac{P \times Q}{\text{LCM}}$
  • This often requires polynomial long division

What is polynomial long division for LCM? Example: Find LCM if $P \times Q = x^4 + 3x^3 - 12x^2 - 20x + 48$ and HCF = $x - 2$

  • $\text{LCM} = \frac{x^4 + 3x^3 - 12x^2 - 20x + 48}{x - 2}$
  • Perform long division:
  • $x^4 \div x = x^3$ → multiply: $x^3(x - 2) = x^4 - 2x^3$ → subtract: $5x^3 - 12x^2$
  • $5x^3 \div x = 5x^2$ → multiply: $5x^2(x - 2) = 5x^3 - 10x^2$ → subtract: $-2x^2 - 20x$
  • $-2x^2 \div x = -2x$ → multiply: $-2x(x - 2) = -2x^2 + 4x$ → subtract: $-24x + 48$
  • $-24x \div x = -24$ → multiply: $-24(x - 2) = -24x + 48$ → subtract: $0$
  • LCM = $x^3 + 5x^2 - 2x - 24$

How do we find a missing polynomial ($Q$)? Given $P$, HCF, and LCM:

  • From $P \times Q = \text{HCF} \times \text{LCM}$
  • $Q = \frac{\text{HCF} \times \text{LCM}}{P}$
  • Example: If $P = (x - 1)$, HCF = $(x - 1)$, LCM = $(x - 1)(x + 1)(x^2 + 1)$
  • $Q = \frac{(x - 1) \times (x - 1)(x + 1)(x^2 + 1)}{(x - 1)} = (x - 1)(x + 1)(x^2 + 1)$

How do we verify using factorization? Factorize both $P$ and $Q$ to confirm HCF and LCM:

  • HCF = product of common factors with smallest powers
  • LCM = product of all distinct factors with highest powers
  • Check that $P \times Q = \text{HCF} \times \text{LCM}$ holds

What algebraic identities help with factorization?

  • Difference of squares: $a^2 - b^2 = (a + b)(a - b)$
  • Sum of cubes: $a^3 + b^3 = (a + b)(a^2 - ab + b^2)$
  • Difference of cubes: $a^3 - b^3 = (a - b)(a^2 + ab + b^2)$
  • Square of sum/difference: $(a \pm b)^2 = a^2 \pm 2ab + b^2$

Example - Finding second polynomial: Given $P = x^2 - 3x + 2$, HCF = $x - 1$, LCM = $x^3 - 4x^2 + 5x - 2$, find $Q$.

  • $P \times Q = \text{HCF} \times \text{LCM}$
  • $Q = \frac{\text{HCF} \times \text{LCM}}{P} = \frac{(x - 1)(x^3 - 4x^2 + 5x - 2)}{x^2 - 3x + 2}$
  • Factorize $P = (x - 1)(x - 2)$
  • $Q = \frac{(x - 1)(x^3 - 4x^2 + 5x - 2)}{(x - 1)(x - 2)} = \frac{x^3 - 4x^2 + 5x - 2}{x - 2}$
  • Perform long division: $x^3 \div x = x^2$, etc.
  • Result: $Q = x^2 - 2x + 1 = (x - 1)^2$

Key points to remember:

  • The formula $P \times Q = \text{HCF} \times \text{LCM}$ works for algebraic polynomials
  • Constant factors may need adjustment (numerical constants are often ignored)
  • Long division must be accurate for correct LCM/HCF calculation
  • Always factorize completely to verify results
  • Handle negative signs carefully during multiplication

Common mistakes to avoid:

  • Forgetting that the formula applies to polynomials, not just numbers
  • Incorrect polynomial long division (check each step)
  • Not factorizing completely before verifying
  • Sign errors in algebraic multiplication
