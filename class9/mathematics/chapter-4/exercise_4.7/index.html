What is the square root of a polynomial? Exercise 4.7, "Square Root of Polynomials," explores systematic methods for determining the square root of complex algebraic expressions. The square root of a polynomial is another polynomial which when multiplied by itself gives the original polynomial.

What are the two methods for finding square root of polynomials?

  • Square Root by Factorization Method - for expressions that are perfect squares
  • Square Root by Division Method - for higher-degree polynomials and complex expressions

Square Root by Factorization Method: This method uses algebraic identities to condense expressions before taking the root.

What algebraic identities are used for factorization method?

  • $(a + b)^2 = a^2 + 2ab + b^2$
  • $(a - b)^2 = a^2 - 2ab + b^2$
  • $(a + b + c)^2 = a^2 + b^2 + c^2 + 2ab + 2bc + 2ca$

Example - Square root by factorization: Find square root of $4x^2 + 12x + 9$

  • $4x^2 + 12x + 9 = (2x)^2 + 2(2x)(3) + 3^2 = (2x + 3)^2$
  • Therefore, square root = $\sqrt{(2x + 3)^2} = 2x + 3$

Example - Square root of trinomial square: Find square root of $x^2 + y^2 + z^2 + 2xy + 2yz + 2zx$

  • This matches $(x + y + z)^2$ identity
  • Therefore, square root = $x + y + z$

Square Root by Division Method: This method is used for higher-degree polynomials and expressions that are not immediately recognizable as perfect squares.

What are the steps for division method?

  • Step 1: Arrange terms in descending powers of the variable (e.g., $x^4 + 2x^3 + 3x^2 + 2x + 1$)
  • Step 2: Take square root of first term (divide exponent by 2)
  • Step 3: Subtract the square of the quotient from the polynomial
  • Step 4: Bring down next terms
  • Step 5: Double the current quotient and find next term
  • Step 6: Repeat until remainder is zero

How do we handle fractional terms in square root? For expressions with fractional powers like $x^4 + \frac{1}{x^4} + 2$:

  • Recognize pattern: $x^4 + 2 + \frac{1}{x^4} = (x^2)^2 + 2(x^2)(\frac{1}{x^2}) + (\frac{1}{x^2})^2 = (x^2 + \frac{1}{x^2})^2$
  • Square root = $x^2 + \frac{1}{x^2}$

What is the importance of rearranging terms? Before starting division method, always rearrange terms in descending powers (or ascending powers for fractional exponents):

  • Example: $x^4 + 2x^3 + 3x^2 + 2x + 1$ is already in descending order
  • Example: $\frac{1}{x^4} + \frac{2}{x^2} + 1$ should be written as $x^{-4} + 2x^{-2} + 1$ or rearrange as $1 + 2x^{-2} + x^{-4}$

How do we find what should be added/subtracted to make a perfect square? Find the missing term to complete the square:

  • For polynomial $P(x)$, find $k$ such that $P(x) + k$ is a perfect square
  • Perform division method, see what remainder appears
  • Add or subtract the remainder to make it zero

Example - Find value of k to make perfect square: Find $k$ such that $x^4 + 6x^3 + 11x^2 + 6x + k$ is a perfect square.

  • Perform division method on $x^4 + 6x^3 + 11x^2 + 6x + k$
  • First term: $\sqrt{x^4} = x^2$
  • Quotient becomes $x^2 + 3x + 1$
  • Remainder: $(k - 1)$
  • For perfect square, remainder must be 0 → $k - 1 = 0$ → $k = 1$

How do we solve for unknown coefficients ($p$, $q$, $k$)? When a polynomial is given as a perfect square with unknown coefficients:

  • Step 1: Perform division method including the unknown
  • Step 2: Set the remainder to zero (condition for perfect square)
  • Step 3: Equate coefficients to find unknowns

Example - Find p and q: If $x^4 + px^3 + qx^2 - 8x + 4$ is a perfect square, find $p$ and $q$.

  • Assume square root is $x^2 + ax + b$
  • Square it: $x^4 + 2ax^3 + (a^2 + 2b)x^2 + 2abx + b^2$
  • Compare with given polynomial:
  • $2a = p$, $a^2 + 2b = q$, $2ab = -8$, $b^2 = 4$
  • $b^2 = 4$ → $b = 2$ or $b = -2$
  • $2ab = -8$ → if $b = 2$, then $4a = -8$ → $a = -2$; if $b = -2$, then $-4a = -8$ → $a = 2$
  • $p = 2a$ → if $a = -2$, $p = -4$; if $a = 2$, $p = 4$
  • $q = a^2 + 2b$ → if $a = -2$, $b = 2$: $q = 4 + 4 = 8$; if $a = 2$, $b = -2$: $q = 4 - 4 = 0$
  • Therefore $(p,q) = (-4,8)$ or $(4,0)$

Key rules for square root of polynomials:

  • For perfect square trinomials: $a^2 \pm 2ab + b^2 = (a \pm b)^2$
  • For division method: remainder must be zero for exact square root
  • Rearrange terms in descending order before division
  • For fractional terms, use ascending order (negative exponents)
  • Double the current quotient when finding next term in division method

Common mistakes to avoid:

  • Forgetting to rearrange terms before starting division method
  • Incorrect handling of fractional exponents (e.g., $\sqrt{x^4} = x^2$, $\sqrt{1/x^4} = 1/x^2$)
  • Not setting remainder to zero for perfect square conditions
  • Sign errors when squaring binomials
