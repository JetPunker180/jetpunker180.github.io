What is the relationship between interior and exterior angles? For any polygon, at each vertex:

  • Interior angle $i$ and exterior angle $e$ are supplementary: $i + e = 180^\circ$
  • This holds for both regular and irregular polygons

How do we calculate the number of sides from exterior angle? For a regular polygon:

  • $n = \frac{360^\circ}{e}$ where $e$ is one exterior angle
  • Example: Exterior angle $45^\circ$ → $n = 360/45 = 8$ sides (octagon)
  • Exterior angle $30^\circ$ → $n = 360/30 = 12$ sides (dodecagon)

How do we calculate the sum of interior angles? For any polygon with $n$ sides:

  • $S = (n - 2) \times 180^\circ$
  • Example: Decagon ($n = 10$): $S = (10 - 2) \times 180^\circ = 8 \times 180^\circ = 1440^\circ$
  • Example: If sum is $2880^\circ$, then $(n - 2) = 2880/180 = 16$, so $n = 18$ sides

How do we find the number of diagonals in a convex polygon?

  • $D = \frac{n(n - 3)}{2}$
  • Example: Polygon with $n = 7$ sides: $D = 7 \times 4 / 2 = 28/2 = 14$ diagonals
  • Example: If $D = 14$, then \frac{n(n-3)}{2} = 14 → $n(n-3) = 28$ → $n^2 - 3n - 28 = 0$ → $(n - 7)(n + 4) = 0$ → $n = 7$ (positive solution)

How do we check if a regular polygon is possible? For a regular polygon to exist:

  • $360^\circ$ must be divisible by the exterior angle $e$
  • Example: $e = 50^\circ$ → $n = 360/50 = 7.2$, which is not an integer → impossible
  • Example: $e = 40^\circ$ → $n = 360/40 = 9$ sides → possible (nonagon)

What are the minimum interior angles? For regular polygons:

  • Minimum interior angle occurs for triangle: $i = 60^\circ$ (equilateral triangle)
  • Maximum interior angle approaches $180^\circ$ as $n \to \infty$
  • Exterior angle approaches $0^\circ$ as $n$ increases

How do we solve for unknown angles in irregular polygons? The sum of exterior angles of any polygon (convex) is always $360^\circ$, regardless of the number of sides.

  • For irregular polygon: sum of all exterior angles = $360^\circ$
  • Set up equation: $e_1 + e_2 + e_3 + ... + e_n = 360^\circ$
  • Then use $i_k = 180^\circ - e_k$ to find interior angles

Example - Finding interior angle of regular polygon: Find interior angle of a regular hexagon ($n=6$).

  • Exterior angle $e = 360/6 = 60^\circ$
  • Interior angle $i = 180^\circ - 60^\circ = 120^\circ$
  • Check: Sum of interior angles = $6 \times 120^\circ = 720^\circ$, and $(6-2) \times 180^\circ = 4 \times 180^\circ = 720^\circ$ ✓

Example - Finding number of sides from interior angle: A regular polygon has interior angle $140^\circ$. Find $n$.

  • $i = 140^\circ$ → $e = 180^\circ - 140^\circ = 40^\circ$
  • $n = 360^\circ / 40^\circ = 9$ sides (nonagon)

Example - Irregular polygon exterior angles: In an irregular pentagon, exterior angles are $x$, $2x$, $3x$, $4x$, $5x$. Find $x$ and each exterior angle.

  • Sum: $x + 2x + 3x + 4x + 5x = 360^\circ$ → $15x = 360^\circ$ → $x = 24^\circ$
  • Exterior angles: $24^\circ, 48^\circ, 72^\circ, 96^\circ, 120^\circ$
  • Check sum: $24+48+72+96+120 = 360^\circ$ ✓

Key formulas summary:

  • $i + e = 180^\circ$
  • $n = 360^\circ / e$ (regular polygon)
  • $S = (n - 2) \times 180^\circ$ (sum of interior angles)
  • $D = n(n - 3)/2$ (number of diagonals)
  • Sum of exterior angles (any polygon) = $360^\circ$
