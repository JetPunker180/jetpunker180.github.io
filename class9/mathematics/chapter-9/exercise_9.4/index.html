How do we determine if two solids are similar? Two solids are similar if all their corresponding linear dimensions are in the same ratio.

  • For similar rectangular solids: $\frac{L_1}{L_2} = \frac{W_1}{W_2} = \frac{H_1}{H_2} = k$ (scale factor)
  • For similar cylinders: $\frac{r_1}{r_2} = \frac{h_1}{h_2} = k$
  • For similar cones: $\frac{r_1}{r_2} = \frac{h_1}{h_2} = \frac{l_1}{l_2} = k$
  • If even one ratio differs, the solids are not similar

What is the relationship between linear ratio and volume? For similar solids:

  • Volume ratio: $\frac{V_1}{V_2} = k^3$ (cube of linear scale factor)
  • Surface area ratio: $\frac{S_1}{S_2} = k^2$ (square of linear scale factor)
  • Example: If linear scale factor $k = 2$, then area ratio = $4$, volume ratio = $8$

How do we find missing linear dimensions from volume ratio?

  • $\frac{V_1}{V_2} = k^3$, so $k = \sqrt[3]{\frac{V_1}{V_2}}$
  • Then $L_2 = L_1 \times k$ or $L_2 = L_1 / k$ depending on direction
  • Example: If $V_1 = 27$ cm³, $V_2 = 125$ cm³, and $L_1 = 3$ cm, then $k = \sqrt[3]{27/125} = \frac{3}{5}$, $L_2 = 3 \times \frac{5}{3} = 5$ cm

How do we calculate unknown surface areas?

  • $S_{\text{new}} = S_{\text{old}} \times k^2$ (if scaling up)
  • $S_{\text{new}} = S_{\text{old}} \div k^2$ (if scaling down)
  • Example: Similar cylinders with height ratio $1:5$. If $k = 5$, area ratio = $25$, volume ratio = $125$

What is the mass-volume relationship for similar objects? For similar objects made of the same material:

  • Mass $\propto$ Volume (since density is constant)
  • $\frac{m_1}{m_2} = \frac{V_1}{V_2} = k^3$
  • Example: If a scale model is $1:10$ linear scale, model mass is $\frac{1}{1000}$ of actual mass

How do we solve scale model problems?

  • Linear scale factor $k = \frac{\text{model dimension}}{\text{actual dimension}}$
  • Model volume $\times k^3 =$ actual volume (if scaling up, use $1/k$)
  • Example: 1:10 scale model bus. If model volume = $0.5$ m³, actual volume = $0.5 \times (10)^3 = 0.5 \times 1000 = 500$ m³
  • If actual mass = $5000$ kg, model mass = $5000 \div (10)^3 = 5000 \div 1000 = 5$ kg

Example - Similar cylinders: Two similar cylinders have heights in ratio $1:5$. Find the ratio of their volumes and surface areas.

  • Linear scale factor $k = 5$
  • Volume ratio = $k^3 = 125 : 1$
  • Surface area ratio = $k^2 = 25 : 1$

Example - Finding height of similar pyramid: Two similar pyramids have volumes $64$ cm³ and $216$ cm³. If the smaller pyramid has height $4$ cm, find the height of the larger pyramid.

  • $k^3 = \frac{216}{64} = \frac{27}{8}$ → $k = \sqrt[3]{27/8} = \frac{3}{2}$
  • $h_{\text{larger}} = h_{\text{smaller}} \times k = 4 \times \frac{3}{2} = 6$ cm

How do we handle capacity problems (chlorine in a pool)? For similar containers, the volume of liquid (or chemical) required scales with $k^3$.

  • If two pools are similar, the amount of chlorine needed is proportional to volume
  • Chlorine ratio = (linear scale factor)$^3$

Key formulas summary:

  • Linear scale factor $k = \frac{L_1}{L_2} = \frac{H_1}{H_2} = \frac{r_1}{r_2}$
  • Surface area ratio = $k^2$
  • Volume ratio = $k^3$
  • Mass ratio = $k^3$ (same material)
  • $k = \sqrt[3]{\frac{V_1}{V_2}}$
  • $k = \sqrt{\frac{S_1}{S_2}}$
