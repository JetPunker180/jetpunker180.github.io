What are angle of elevation and angle of depression?

  • Angle of Elevation: The angle between the horizontal line of sight and the upward direction when looking at an object above.
  • Angle of Depression: The angle between the horizontal line of sight and the downward direction when looking at an object below.
  • Key property: The angle of depression from a height is numerically equal to the angle of elevation from the ground point (alternate interior angles).

How do we choose the correct trigonometric ratio? Based on the given sides:

  • $\tan \theta = \frac{\text{opposite}}{\text{adjacent}}$ → Use when you have height (opposite) and distance (adjacent)
  • $\sin \theta = \frac{\text{opposite}}{\text{hypotenuse}}$ → Use when you have height and hypotenuse (inclined length)
  • $\cos \theta = \frac{\text{adjacent}}{\text{hypotenuse}}$ → Use when you have distance and hypotenuse
  • Pythagorean theorem: $a^2 + b^2 = c^2$ for finding unknown sides

How do we find the height of an object from a distance? Use the tangent function with angle of elevation.

  • Formula: $\tan \theta = \frac{h}{d}$ → $h = d \times \tan \theta$
  • Example: From a distance of 20 m, the angle of elevation to the top of a tree is $30^\circ$. Find the tree height.
  • $h = 20 \times \tan 30^\circ = 20 \times \frac{1}{\sqrt{3}} \approx 20 \times 0.5774 \approx 11.55$ m

How do we find the distance when height and angle are given? Rearrange $\tan \theta = h/d$ → $d = \frac{h}{\tan \theta} = h \cot \theta$

How do we find the distance between two objects from an observer?

  • Objects on the same side: Distance = $|x - y|$ (difference of distances)
  • Objects on opposite sides: Distance = $x + y$ (sum of distances)
  • Example: Two boats on same side of a lighthouse at angles of depression $30^\circ$ and $45^\circ$. Find distance between them.
  • Let lighthouse height = $h$. Distance to nearer boat = $h/\tan 45^\circ = h$, distance to farther boat = $h/\tan 30^\circ = h\sqrt{3}$
  • Distance between boats = $h\sqrt{3} - h = h(\sqrt{3} - 1)$

How do we find the length of an inclined object using sine? For objects like slides, ramps, or ladders:

  • Formula: $\sin \theta = \frac{\text{opposite}}{\text{hypotenuse}} = \frac{h}{L}$ → $L = \frac{h}{\sin \theta}$
  • Example: A slide has height $h = 3$ m and makes $30^\circ$ with the ground. Find slide length.
  • $L = \frac{3}{\sin 30^\circ} = \frac{3}{0.5} = 6$ m

How do we find heights in geometric shapes (e.g., equilateral triangle)?

  • In an equilateral triangle, altitude bisects the base
  • Using Pythagorean theorem: $h^2 = a^2 - (\frac{a}{2})^2 = a^2 - \frac{a^2}{4} = \frac{3a^2}{4}$
  • $h = \frac{\sqrt{3}}{2} a$
  • Example: Equilateral triangle window with side $a = 2$ m → height $h = \sqrt{3} \approx 1.732$ m

How do we solve complex multi-angle observation problems? When two observations are taken from different points, equating expressions for height.

  • Example: From point A, angle of elevation to tower top = $30^\circ$. From point B, 50 m closer, angle = $45^\circ$. Find tower height.
  • Let $h$ = tower height, $x$ = distance from B to tower
  • From B: $\tan 45^\circ = h/x$ → $h = x$
  • From A: $\tan 30^\circ = h/(x + 50)$ → $\frac{1}{\sqrt{3}} = \frac{h}{x + 50}$
  • Substitute $h = x$: $\frac{1}{\sqrt{3}} = \frac{x}{x + 50}$
  • Cross-multiply: $x + 50 = x\sqrt{3}$ → $x\sqrt{3} - x = 50$ → $x(\sqrt{3} - 1) = 50$
  • $x = \frac{50}{\sqrt{3} - 1} \approx \frac{50}{0.732} \approx 68.3$ m
  • $h = x \approx 68.3$ m

What are the key values to remember?

  • $\tan 45^\circ = 1$ (simplifies calculations significantly)
  • $\tan 30^\circ = \frac{1}{\sqrt{3}} \approx 0.577$
  • $\tan 60^\circ = \sqrt{3} \approx 1.732$
  • $\sin 30^\circ = \frac{1}{2} = 0.5$, $\sin 45^\circ = \frac{1}{\sqrt{2}} \approx 0.707$, $\sin 60^\circ = \frac{\sqrt{3}}{2} \approx 0.866$

Important note: Always draw a clear diagram first to correctly identify the perpendicular (height), base (distance), and hypotenuse (inclined length).
