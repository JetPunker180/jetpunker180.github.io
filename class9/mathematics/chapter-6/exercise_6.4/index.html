What are the fundamental trigonometric identities? These are the core identities derived from the Pythagorean theorem:

  • Fundamental Identity: $\sin^2 \theta + \cos^2 \theta = 1$
  • Derived Identity 1: $1 + \tan^2 \theta = \sec^2 \theta$
  • Derived Identity 2: $1 + \cot^2 \theta = \csc^2 \theta$

How do we prove trigonometric relations? Use fundamental identities to transform the Left Hand Side (LHS) into the Right Hand Side (RHS).

  • Example: Simplify $(1 - \sin^2 \theta) \sec^2 \theta$
  • $1 - \sin^2 \theta = \cos^2 \theta$
  • $\sec^2 \theta = \frac{1}{\cos^2 \theta}$
  • Expression: $\cos^2 \theta \times \frac{1}{\cos^2 \theta} = 1$

How do we prove complex identities like $\sin^6 \theta + \cos^6 \theta = 1 - 3 \sin^2 \theta \cos^2 \theta$?

  • Use the identity $a^3 + b^3 = (a + b)(a^2 - ab + b^2)$ with $a = \sin^2 \theta$, $b = \cos^2 \theta$
  • $\sin^6 \theta + \cos^6 \theta = (\sin^2 \theta)^3 + (\cos^2 \theta)^3$
  • $= (\sin^2 \theta + \cos^2 \theta)(\sin^4 \theta - \sin^2 \theta \cos^2 \theta + \cos^4 \theta)$
  • $= 1 \times (\sin^4 \theta + \cos^4 \theta - \sin^2 \theta \cos^2 \theta)$
  • Since $\sin^4 \theta + \cos^4 \theta = (\sin^2 \theta + \cos^2 \theta)^2 - 2 \sin^2 \theta \cos^2 \theta = 1 - 2 \sin^2 \theta \cos^2 \theta$
  • $= (1 - 2 \sin^2 \theta \cos^2 \theta) - \sin^2 \theta \cos^2 \theta = 1 - 3 \sin^2 \theta \cos^2 \theta$
  • Identity proved ✓

How do we solve for an unknown angle in a given interval? Isolate the trigonometric function and find the inverse within the specified range.

  • Example: Solve $2 \sin^2 \theta = \frac{1}{4}$ for $0 \leq \theta \leq \frac{\pi}{2}$
  • $\sin^2 \theta = \frac{1}{4}$ → $\sin \theta = \pm \frac{1}{2}$
  • Within $0 \leq \theta \leq \frac{\pi}{2}$, sine is positive → $\sin \theta = \frac{1}{2}$
  • $\theta = \sin^{-1}(\frac{1}{2}) = 30^\circ = \frac{\pi}{6}$ rad

How do we solve equations like $\sec^2 \theta - 2 \tan^2 \theta = 0$? Convert to a single function using identities.

  • $\sec^2 \theta = 1 + \tan^2 \theta$
  • Equation: $(1 + \tan^2 \theta) - 2 \tan^2 \theta = 0$ → $1 - \tan^2 \theta = 0$
  • $\tan^2 \theta = 1$ → $\tan \theta = \pm 1$
  • For $0 \leq \theta \leq \frac{\pi}{2}$, $\tan \theta = 1$ → $\theta = 45^\circ = \frac{\pi}{4}$ rad

How do we solve right-angled triangles? Use the Pythagorean theorem and trigonometric ratios.

  • Pythagorean Theorem: $a^2 + b^2 = c^2$ (where $c$ is the hypotenuse)
  • Trigonometric ratios:
    • $\sin \theta = \frac{\text{opposite}}{\text{hypotenuse}} = \frac{a}{c}$
    • $\cos \theta = \frac{\text{adjacent}}{\text{hypotenuse}} = \frac{b}{c}$
    • $\tan \theta = \frac{\text{opposite}}{\text{adjacent}} = \frac{a}{b}$
  • Angle sum: $\angle A + \angle B + \angle C = 180^\circ$ (with $\angle C = 90^\circ$)

Example - Solving a right triangle: Given $\angle C = 90^\circ$, $a = 3$ cm, $b = 4$ cm.

  • Hypotenuse: $c = \sqrt{a^2 + b^2} = \sqrt{9 + 16} = \sqrt{25} = 5$ cm
  • $\tan A = \frac{a}{b} = \frac{3}{4} = 0.75$ → $A = \tan^{-1}(0.75) \approx 36.87^\circ$
  • $\angle B = 90^\circ - A \approx 53.13^\circ$

How do we apply trigonometry to algebraic proofs? Prove relations like $x^2 + y^2 = m^2 + n^2$ by squaring and adding equations containing $\sin \theta$ and $\cos \theta$.

  • Example: If $x = m \cos \theta - n \sin \theta$ and $y = m \sin \theta + n \cos \theta$, prove $x^2 + y^2 = m^2 + n^2$.
  • Square and add: $x^2 + y^2 = (m \cos \theta - n \sin \theta)^2 + (m \sin \theta + n \cos \theta)^2$
  • Expand: $m^2 \cos^2 \theta - 2mn \cos \theta \sin \theta + n^2 \sin^2 \theta + m^2 \sin^2 \theta + 2mn \sin \theta \cos \theta + n^2 \cos^2 \theta$
  • Cancel $-2mn$ and $+2mn$ terms → $m^2(\cos^2 \theta + \sin^2 \theta) + n^2(\sin^2 \theta + \cos^2 \theta) = m^2(1) + n^2(1) = m^2 + n^2$

Important reminder: Always check the quadrant/interval when taking square roots in trigonometric equations to select the correct sign (positive or negative).
