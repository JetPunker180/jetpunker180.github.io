What are the exact trigonometric values for standard angles? Memorize these values for common angles:

| Angle | $\sin$ | $\cos$ | $\tan$ | |-------|--------|--------|--------| | $0^\circ$ | $0$ | $1$ | $0$ | | $30^\circ$ | $\frac{1}{2}$ | $\frac{\sqrt{3}}{2}$ | $\frac{1}{\sqrt{3}}$ | | $45^\circ$ | $\frac{1}{\sqrt{2}}$ | $\frac{1}{\sqrt{2}}$ | $1$ | | $60^\circ$ | $\frac{\sqrt{3}}{2}$ | $\frac{1}{2}$ | $\sqrt{3}$ | | $90^\circ$ | $1$ | $0$ | undefined | | $180^\circ$ | $0$ | $-1$ | $0$ | | $270^\circ$ | $-1$ | $0$ | undefined | | $360^\circ$ | $0$ | $1$ | $0$ |

How do we evaluate expressions using exact values? Substitute the exact values from the table.

  • Example: $\sin 60^\circ - \cos 30^\circ = \frac{\sqrt{3}}{2} - \frac{\sqrt{3}}{2} = 0$

What is the ASTC rule for quadrant signs? ASTC stands for "All Students Take Calculus" to remember which ratios are positive in each quadrant:

  • Quadrant I (0°-90°): A = All ratios positive
  • Quadrant II (90°-180°): S = Sine positive (others negative)
  • Quadrant III (180°-270°): T = Tangent positive (others negative)
  • Quadrant IV (270°-360°): C = Cosine positive (others negative)

How do we find multiple solutions for $\theta$ in $0 < \theta < 2\pi$? Using the ASTC rule:

  • Step 1: Find reference angle $\alpha = \sin^{-1}(|\text{value}|)$
  • Step 2: Identify quadrants where the ratio is positive/negative
  • Step 3: Calculate $\theta$ in each quadrant: I = $\alpha$, II = $180^\circ - \alpha$, III = $180^\circ + \alpha$, IV = $360^\circ - \alpha$

Example - Finding $\theta$ for $\sin \theta = \frac{\sqrt{2}}{2}$:

  • Reference angle: $\sin^{-1}(\frac{\sqrt{2}}{2}) = 45^\circ = \frac{\pi}{4}$ rad
  • Sine is positive in Quadrants I and II
  • Quadrant I: $\theta = 45^\circ = \frac{\pi}{4}$ rad
  • Quadrant II: $\theta = 180^\circ - 45^\circ = 135^\circ = \frac{3\pi}{4}$ rad
  • Solution set: $\{\frac{\pi}{4}, \frac{3\pi}{4}\}$

Example - Finding $\theta$ for $\tan \theta = 1$:

  • Reference angle: $\tan^{-1}(1) = 45^\circ = \frac{\pi}{4}$ rad
  • Tangent is positive in Quadrants I and III
  • Quadrant I: $\theta = 45^\circ = \frac{\pi}{4}$ rad
  • Quadrant III: $\theta = 180^\circ + 45^\circ = 225^\circ = \frac{5\pi}{4}$ rad
  • Solution set: $\{\frac{\pi}{4}, \frac{5\pi}{4}\}$

How do we verify trigonometric identities? Substitute a specific value into both sides to check equality.

  • Example: Verify $\cos 2\theta = 1 - 2\sin^2 \theta$ for $\theta = \frac{\pi}{6}$
  • LHS: $\cos(2 \times \frac{\pi}{6}) = \cos(\frac{\pi}{3}) = \frac{1}{2}$
  • RHS: $1 - 2\sin^2(\frac{\pi}{6}) = 1 - 2 \times (\frac{1}{2})^2 = 1 - 2 \times \frac{1}{4} = 1 - \frac{1}{2} = \frac{1}{2}$
  • LHS = RHS, identity verified

What are the key trigonometric identities?

  • Fundamental Identity: $\sin^2 \theta + \cos^2 \theta = 1$
  • Double Angle Identities: $\cos 2\theta = \cos^2 \theta - \sin^2 \theta = 1 - 2\sin^2 \theta = 2\cos^2 \theta - 1$
  • Double Angle (Tangent): $\tan 2\theta = \frac{2\tan \theta}{1 - \tan^2 \theta}$
  • Triple Angle (Sine): $\sin 3\theta = 3\sin \theta - 4\sin^3 \theta$
  • Reciprocal Identities: $\csc \theta = \frac{1}{\sin \theta}$, $\sec \theta = \frac{1}{\cos \theta}$, $\cot \theta = \frac{1}{\tan \theta}$
  • Quotient Identities: $\tan \theta = \frac{\sin \theta}{\cos \theta}$, $\cot \theta = \frac{\cos \theta}{\sin \theta}$

How do we find all six trigonometric ratios from one given ratio? Given a ratio and the quadrant:

  • Step 1: Use $\sin^2 \theta + \cos^2 \theta = 1$ to find missing sine or cosine
  • Step 2: Determine the correct sign based on quadrant (ASTC rule)
  • Step 3: Find $\tan \theta = \frac{\sin \theta}{\cos \theta}$
  • Step 4: Find reciprocals: $\csc \theta = 1/\sin \theta$, $\sec \theta = 1/\cos \theta$, $\cot \theta = 1/\tan \theta$

Example - Find all ratios given $\cos \theta = -\frac{3}{5}$ and $\theta$ in Quadrant II:

  • $\sin^2 \theta = 1 - \cos^2 \theta = 1 - \frac{9}{25} = \frac{16}{25}$ → $\sin \theta = \pm \frac{4}{5}$
  • Quadrant II → sine positive → $\sin \theta = \frac{4}{5}$
  • $\tan \theta = \frac{\sin \theta}{\cos \theta} = \frac{4/5}{-3/5} = -\frac{4}{3}$
  • $\csc \theta = \frac{5}{4}$, $\sec \theta = -\frac{5}{3}$, $\cot \theta = -\frac{3}{4}$

Common boundary cases: Equations like $\cos \theta = 0$ have multiple solutions: $90^\circ$ and $270^\circ$ (or $\pi/2$ and $3\pi/2$).
